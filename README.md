# Cybersecurity Internship Tasks

| Task | File | Run |
|------|------|-----|
| 1. Password Strength Analyzer | `task1_password_strength_analyzer.py` | `python task1_password_strength_analyzer.py` |
| 2. Vulnerability Scanner | `task2_vulnerability_scanner.py` | `python task2_vulnerability_scanner.py 127.0.0.1` |
| 3. Phishing Email Detection | `task3_phishing_email_detection.py` | `python task3_generate_dataset.py` then `python task3_phishing_email_detection.py` |

Install dependencies for Task 3: `pip install -r requirements.txt`

Task 1 and Task 2 use only the Python standard library.

Use the scanner only on systems you own or have written permission to test.
